# Auth Service

Сервис аутентификации и авторизации пользователей для онлайн-кинотеатра.

---
Проект выполняется индивидуально

[Ссылка на репозиторий](https://github.com/nyutamaksimova/Auth_sprint_1)

---
## Стек технологий

- Python 3.12
- FastAPI
- PostgreSQL
- SQLAlchemy 2.0 (Async)
- Redis
- JWT (Access + Refresh Token)
- Docker / Docker Compose
- Pytest

---

# Возможности

## Аутентификация

- Регистрация пользователя
- Авторизация пользователя
- Выдача пары JWT-токенов
    - Access Token
    - Refresh Token
- Обновление Access Token
- Выход пользователя из аккаунта
- Получение информации о текущем пользователе

## Авторизация

Реализована ролевая модель доступа (RBAC).

Поддерживаемые роли:

- USER
- MODERATOR
- CONTENT_MANAGER
- ADMIN
- SUPER_ADMIN

SUPER_ADMIN обладает полным доступом ко всем ресурсам системы.

## Управление ролями

Администратор может:

- назначить пользователю роль;
- изменить роль пользователя;
- проверить наличие определенного доступа.

# Запуск

```
docker compose up --build
```

Документация будет доступна

```
http://localhost:8000/docs
```

# Запуск тестов

Функциональные тесты запускаются в отдельной инфраструктуре.

```
docker compose -f docker-compose.test.yml up --build
```
